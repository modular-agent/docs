# 最初のワークフロー

Modular Agent Desktop のエディタでワークフローを作成して実行してみましょう。

## 1. プリセットを作成する

**プリセット**とは、保存されたワークフロー、つまり接続されたエージェントのグラフです。Modular Agent を起動し、既存のプリセットを開くか、新しいプリセットを作成します。

## 2. エージェントを追加する

- キャンバス上を**右クリック**して **Add agent(エージェントを追加)** を選択する
- または、キャンバス上を**ダブルクリック**してエージェント一覧を開く

カタログからエージェントを選びます。たとえば *Text Input* エージェントと *Chat Completion* エージェントを追加してみましょう。

## 3. ポートを接続する

各エージェントのブロックには**入力ポート**と**出力ポート**が表示されます。**ポート間をドラッグ**してエージェント同士を接続します。ワークフローの実行中は、この接続に沿ってデータが流れます。

## 4. エージェントを設定する

エージェントを選択すると設定を編集できます。モデル名、URL、テンプレートなどのパラメータはエージェントの種類によって異なります。LLM 連携などの一部のエージェントは、API キーといったアプリ設定の**グローバル設定**も参照します。

## 5. 実行する

キャンバスを右クリックして **Play(再生)** を選択するか、`Ctrl+.`(macOS は `Cmd+.`)を押します。パイプラインが起動し、接続されたエージェントの間をデータがリアルタイムに流れます。停止するには同じメニューの **Stop(停止)** を使います。

## ヒント

- **Auto-Start(自動起動)** — アプリの起動時にプリセットを自動実行するように設定できます
- **System Tray(システムトレイ)** — システムトレイからワークフローをバックグラウンドで動かし続けられます
- **Import/Export(インポート / エクスポート)** — プリセットは JSON ファイルなので、共有したり手作業で編集したりできます(詳しくは[プリセット形式](/concepts/preset-format)を参照)
