# UI ヒントとメタデータ

エージェント定義には、ポートや設定に加えて、デスクトップエディタがエージェントブロックを描画する際に使う表示用メタデータを持たせられます。

## UI ヒント

`hint(...)` を使って、定義レベルでヒントを指定します。

```rust
#[modular_agent(
    title = "My Agent",
    category = "LLM",
    hint(color = 3, width = 2, height = 1),
)]
```

| キー | 型 | デフォルト | 説明 |
|-----|-----|---------|------|
| `color` | integer (1–7) | 未設定 | ノードの色インデックス |
| `width` | integer (>0) | 1 | ブロックの幅 |
| `height` | integer (>0) | 1 | ブロックの高さ |

定義レベルのヒントは、そのエージェント型の**すべてのインスタンス**に適用されます。個々のインスタンスは `AgentSpec.extensions` で上書きできます。

## タイトルとカテゴリ

- `title` — ブロック上とカタログに表示される、人が読める名前
- `category` — カタログ内での表示位置を決める `/` 区切りのパス(例: `"Database/SQL"`、`"Text/Transform"`)

## 説明

エージェントの説明は構造体の `///` ドキュメントコメントから取得されます(`description = "..."` 属性を明示した場合はそちらが優先されます)。よく書かれた説明には次の内容が含まれます。

- 1 行の要約に続けて、動作の詳細、エッジケース、エラー条件
- `# Ports` — 各入力ポートと出力ポート
- `# Configuration` — 各設定とそのデフォルト値
- `# Global Configuration` — エージェントが参照するアプリ全体の設定(API キーなど)
- `# Example` — 変換内容が自明でない場合の入出力例

このテキストはエディタに表示されるとともに、パッケージのリファレンスドキュメントも兼ねます。
